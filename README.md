# 🏨 Valle dos Aromas

Site do **Hotel Valle dos Aromas**, localizado em **Urubici - SC**.  
Projeto desenvolvido em **JavaScript puro**, com frontend e um backend simples integrados.

---

## 🌿 Descrição

O **Valle dos Aromas** é um hotel fictício de luxo situado na Serra Catarinense, cercado por montanhas, cachoeiras e natureza exuberante.  
O site apresenta:

- Informações sobre o SPA, vinícola e colheita de morangos
- Sistema de reservas com calendário
- Localização e mapa ilustrativo
- Design elegante em tons de verde e lilás

---

## ⚙️ Tecnologias

- HTML
- CSS
- JavaScript
- Node.js
